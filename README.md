# LearnLab

Адаптивное приложение для обучения программированию: **Python, JavaScript, алгоритмы (на Python) и SQL**.
Работает полностью на устройстве: код исполняется в браузере (Pyodide / sql.js / изолированный Web Worker), прогресс хранится локально.

## Что внутри

| | |
|---|---|
| Маршруты | 4 маршрута, 50 навыков с графом пререквизитов, 445 заданий, 6 пошаговых проектов |
| Типы заданий | выбор ответа (с дистракторами-заблуждениями), предсказание вывода, написание кода, поиск бага, сборка программы (Parsons), самообъяснение |
| Умная диагностика | адаптивный тест при выборе маршрута: следующий вопрос выбирается по информативности с учётом графа навыков, «не знаю», оценка уверенности, объяснимые итоги, ручная корректировка |
| Модель знаний | BKT по навыкам с «мягкими» свидетельствами (подсказки, угадывание, быстрые ответы весят меньше); мастерство только при нескольких самостоятельных решениях разных типов, включая воспроизведение |
| Память | упрощённый FSRS по навыкам (каждое повторение — новая задача), отсроченные проверки через 7/30/90 дней, интерливинг |
| Обратная связь | объяснения ошибок Python/JS/SQL и неверных результатов (return vs print, off-by-one, типы, порядок, NULL, размножение строк в JOIN…) с выбором глубины и тона (дружелюбный / нейтральный / сократический), лестница подсказок |
| Персонализация | цели обучения (5 режимов), 6 профилей-пресетов, 8 тем, акцент, шрифты, плотность, анимации, фон меню, редактор, порог мастерства, целевое удержание, длина сессии и диагностики, виджеты главной |
| Прочее | журнал ошибок и заблуждений, портфолио доказанных навыков (экспорт в Markdown), песочница с пошаговым визуализатором Python, командная палитра (Ctrl+K), экспорт/импорт с проверкой, офлайн (service worker) |

Обоснование механик и источники — [`docs/RESEARCH.md`](docs/RESEARCH.md). Состояние по критериям качества — [`docs/QUALITY.md`](docs/QUALITY.md).

## Запуск

```bash
pnpm install          # postinstall копирует Pyodide и sql.js в public/ (самостоятельный хостинг, без CDN)
pnpm dev              # http://localhost:5173
pnpm build && pnpm preview
```

## Проверки

```bash
pnpm typecheck                      # TypeScript strict
pnpm test                           # юнит-тесты ядра + конвейер контента
ROUTE=py pnpm test:content          # контент одного маршрута (py | js | algo | sql)
npx playwright install chromium     # один раз
pnpm build && pnpm e2e              # сквозные сценарии в Chromium
```

**Конвейер контента** (`tests/content`) исполняет весь учебный материал теми же движками, что и приложение (Pyodide 3.14 и sql.js в Node): выводы примеров, ответы «предскажи вывод», эталонные решения против всех (в т. ч. скрытых) тестов, проверяет, что стартовый/ошибочный код тесты *не* проходит, что SQL-задачи имеют скрытый набор данных, MCQ — ровно один верный ответ, а ссылки на заблуждения существуют. Граф пререквизитов проверяется на ацикличность.

## Архитектура

```
src/core/        чистая логика без UI: types (схема контента), model (BKT, мастерство, отсроченные проверки),
                 srs (FSRS), diagnostic (адаптивная диагностика), planner (план дня, подбор заданий),
                 feedback (объяснения ошибок), settings (схема настроек и пресеты), storage (версии, миграции,
                 резервная копия, импорт/экспорт), graph
src/runner/      исполнение кода: harness.py (Python), jsHarness.ts, sqlHarness.ts — общие для браузера и тестов;
                 pyWorker/jsWorker — изолированные воркеры; runner.ts — таймаут, перезапуск зависших воркеров
src/content/     маршруты: один файл на навык (урок 3 уровней глубины, пример, контрпример, заблуждения, задания)
src/state/       zustand-хранилище, отложенное сохранение, синхронизация между вкладками
src/ui/          экраны и компоненты (CodeMirror 6, SVG-граф навыков, визуализатор)
tests/unit       ядро и харнессы;  tests/content — конвейер контента;  e2e/ — Playwright
```

**Безопасность исполнения кода.** Код ученика выполняется в выделенном Web Worker без DOM и без доступа к localStorage
(прогресс хранится только там); после загрузки рантайма `fetch`, `XMLHttpRequest`, `WebSocket`, `indexedDB`, `caches`
удаляются; JS дополнительно исполняется в strict mode с затенёнными глобалами. Зависание прерывается таймаутом
(настраивается, 2–20 с) с перезапуском воркера; фатальная ошибка интерпретатора тоже ведёт к перезапуску.
Это защита учебного кода самого ученика, а не песочница для недоверенного чужого кода.

**Данные.** Схема состояния версионирована и проверяется (zod) при загрузке и импорте; при повреждении
восстанавливается резервная копия, а повреждённые данные сохраняются отдельно. Сохранение отложенное (300 мс) и
принудительное при скрытии страницы; изменения из другой вкладки подхватываются, а не перезаписываются.
