## Принятые решения из исследования

Реализовано (доказательства — RESEARCH.md): извлечение из памяти с обратной связью, разнесённое повторение по навыкам,
адаптивная диагностика по графу, примеры с пошаговым раскрытием, глубина объяснения по уровню (expertise reversal),
PRIMM (предсказание до запуска), самообъяснение, Parsons-задачи, лестница подсказок по запросу, оценка уверенности
и калибровка, работа с типичными заблуждениями, интерливинг в повторении, геймификация без «серий».

AI-тьютор реализован как опция «свой провайдер»: подсказки в виде наводящих вопросов, без выдачи решения активного задания, с пометкой «может содержать ошибки» и оценкой ответа. Влияние на обучение не измерено.

Отложено: FSRS-6 (выгода в предсказании, не в обучении),
специальные «дислексические» шрифты как доказанное средство (доказательства слабые — есть только опция удобочитаемого шрифта).
